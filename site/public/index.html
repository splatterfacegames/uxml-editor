UXML Editor
Try it Features Download Source

Edit Unity UI files visually. Keep every byte you did not change.

UXML Editor is a visual editor for Unity UI Toolkit documents (UXML) and stylesheets (USS), built on Godot 4.7. Each edit is a patch on the exact text of the file: comments, attribute order, quotes, whitespace and line endings stay as they were.

Open in a new tab

The editor runs in your browser: a Godot web export, about 40 MB, downloaded when you click. The sample is a project with a menu, an options form and nested stylesheets. Edits stay in your browser; Ctrl+S downloads the project as a zip.

Your own project: Ctrl+O. Chrome and Edge open a folder with the File System Access API and save to it. Other browsers open a zip of the project. The editor needs a window at least 1000 pixels wide.

Source text is the truth.

The editor changes a file only with a patch on its exact text. A patch replaces one range of characters; all other bytes stay the same.

An edit that cannot be made as an exact patch stops with a message. It changes no file and adds no undo step. A drag on the canvas, a value in the inspector and a keystroke in the source view are all patches into the same history, so one undo works across every view and every tab.

What it does

Screenshots from the editor, with the menu fixture of the repository.

  • Saves check the disk. Before a write, the editor compares the file with the version it read, and asks when another program changed it.
  • Recovery. Each unsaved edit goes to a journal at once; after a crash the next open asks to recover or discard.
  • Tabs and one history. An undo of an edit in another document shows that document's tab.
  • Typed style fields. Lengths, colours, keywords, assets, angles, times and easings are checked before the edit.

Rendered by godot-uxml

The canvas is godot-uxml, the Godot addon that loads UXML and USS and makes native Godot controls. It matches Unity 6000.3 in 176 of 177 test cases. So the canvas shows what the file looks like in a Godot game, and the editor's own panels are UXML too.

The editor uses godot-uxml's editor APIs: loads through a resolver of unsaved buffers, partial stylesheet reloads, provenance of each declaration, forced states, a transition timeline and hit tests. Choose the runtime theme or Unity's editor skin, dark or light, for the canvas.

Download

Builds for Windows, Linux and macOS are attached to each GitHub release. The editor has no installer: unpack and start it.

No release yet. The release workflow builds the three platforms when a version tag is pushed. Until then, export a build from the source:

    Windows x64

    Native core of godot-uxml. Keep uxml-editor.exe and godot_uxml_native.windows.x86_64.dll in the same folder.

    godot --headless --path . --export-release "Windows Desktop" build/windows/uxml-editor.exe

    Linux x86_64

    GDScript path. Make the file executable and start it.

    godot --headless --path . --export-release "Linux" build/linux/uxml-editor.x86_64

    macOS

    Universal, GDScript path, not signed: open it the first time with Control+click and Open.

    godot --headless --path . --export-release "macOS" build/macos/uxml-editor.zip

    Exports need Godot 4.7.1 (standard build) and its export templates. To run from the source: godot --path . -- --project=fixtures/projects/menu.
